# Blender assets (NOT included in this public repository)
The reel renderer needs three Blender models in this folder: `stadium/`, `ball/`, `racket/` (originally from Blendswap; each came with its own licence file).
Because their licences (attribution / non-commercial terms) have not been cleared for a public MIT repository, they are not committed here.
Get them from the project backup (`tennis-reel-kit.zip` → `tennis-reel-kit/assets/`) or replace them with your own assets that keep the same file names and object names (see `docs/serve_reel/EXTENDING.md`), then run `python3 reel.py check`.
