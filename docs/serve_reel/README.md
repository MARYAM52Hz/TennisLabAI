# serve_reel documentation index

Read in this order:
1. `INPUT_STANDARDS_AND_CALIBRATION.md` - what to film, how to label, how scale is calibrated, fact-checks, reliability grade, charts.
2. `PIPELINE.md` - the stages, in order, with the files each one reads and writes.
3. `DATA_FORMATS.md` - `job.json`, labels pickles, npz files, `metrics.json`, `qc.json`.
4. `STANDARDS_AND_DECISIONS.md` - requirements, decisions, bug table, reference numbers.
5. `EXTENDING.md` - recipes for changing looks, texts, metrics, adding a view; prompt for AI assistants.
6. `HISTORY_AND_INVENTORY.md` - how the project evolved (three eras) and what was delivered.
7. `RESTORE.md` - rebuilding the old flat workspace from `serve_reel/archive_code/`.

Path note: these documents were written for the stand-alone repository: there `kit/` = `serve_reel/` here, `archive/` = `serve_reel/archive_code/`, and `docs/` = `docs/serve_reel/`. Blender assets are not included in this repository (`serve_reel/assets/README_ASSETS.md`).
